This folder contains curriculum graph data used by CoastalTutor's China school-learning route.

CoastalTutor uses its own product names and learner interface. This notice preserves data provenance and is not a user-facing product brand. Changes to this dataset should be recorded here and must retain the applicable attribution and license information.

The downloaded snapshot contains topic nodes, prerequisite edges, diagnostic questions, curriculum-standard mappings, alternative textbook mappings, and legacy-ID aliases. See the source repository's README and provenance documentation for subject coverage, textbook mappings, validation status, and known gaps. Alternative textbook mappings marked “draft” are labeled as such in the learner interface.
